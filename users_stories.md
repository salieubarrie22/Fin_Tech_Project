 User Stories for Fin_Tech_Project

 As a user living in the diaspora:
 I want to send money to my family back home, so they can receive support quickly.
 I want to receive confirmation after a successful transfer.

 As a local user in Sierra Leone:
 I want to receive money in my mobile wallet.
 I want to view transaction history.

 As an Admin:
 I want to monitor transactions in real-time.
 I want to generate reports of daily transaction logs.
